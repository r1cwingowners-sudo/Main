# Sketch

A no-key interactive prototype for a wedding and event décor quote agent.

Run `node server.js`, then open `http://localhost:3000`. Upload a venue photo and Sketch will generate three architecture-preserving décor concepts after the plan button is clicked. All quotes remain **estimates**.

## Next step for real AI

Connect an OpenAI API key to add actual venue-photo analysis and generated décor visuals. The current prototype intentionally keeps all recommendations and pricing simulated.
